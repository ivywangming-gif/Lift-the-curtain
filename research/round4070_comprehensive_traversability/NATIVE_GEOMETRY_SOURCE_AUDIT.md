# Native collision export: source evidence and limits

This is an implementation audit, not a G1 traversability result. A successful parser is insufficient for primary admission without actual shape inventory, coordinate-frame, temporal-coverage and per-trial provenance checks.

The official repository maps the 107.3 extension release to PhysX 5.6.1 and Isaac Sim 5.1.0. This is the relevant public release family for the installed environment; it does not prove that a particular installed binary was built from an identical source checkout. [NVIDIA PhysX repository](https://github.com/NVIDIA-Omniverse/PhysX)

In the matching public release, `streamConvexMesh` obtains the native cooked mesh's vertex pointer and count, copies every vertex, and writes the full array. Its triangle indices come from native polygon/index data. `streamConvexMeshGeometry` records the native mesh reference and scale vector. These are native simulation geometry sources, rather than a request to recook a visual mesh. [107.3 / PhysX 5.6.1 writer, lines 525–591](https://github.com/NVIDIA-Omniverse/PhysX/blob/107.3-omni-and-physx-5.6.1/physx/source/physx/src/omnipvd/OmniPvdPxSampler.cpp#L525-L591)

The scale writer above records `g.scale.scale` but does not explicitly record `PxMeshScale.rotation`. Therefore an arbitrary nonuniform mesh scale cannot be assumed fully described by that field alone. Actual G1 scale values, shape-local transforms and known-geometry diagnostics must establish applicability; unsupported affine cases fail closed. The public definition of a cooked convex mesh as vertices and polygonal faces supports the geometric interpretation but does not remove this frame obligation. [NVIDIA geometry documentation](https://nvidia-omniverse.github.io/PhysX/physx/5.5.1/docs/Geometry.html)

The actual parser-v4 audit found all 27 G1 native convex scale vectors equal to `[1,1,1]`. A scale-axis rotation has no effect for these isotropic scales. The source artifact is `outputs/round4070_comprehensive_traversability/physics_diagnostics/collider_native_omnipvd_v6_stopfix_attempt01/native_pvd_usd_00/native_geometry_parser_v4.json`. It extracts all 39 shapes: 15 convexes with consistent native faces, 12 conservative native-vertex envelopes, eight spheres and four zero-margin convex-core cylinders. This resolves parser coverage, while per-trial mapping and full temporal auditing remain separate admission requirements.

Actual G1 export exposed nonconvexity inconsistencies between some exported triangle planes and the complete associated native vertex set. Original arrays and the size of these discrepancies are retained. For affected shapes, the proposed V5 audit uses the mathematical convex hull of the complete native vertices only as a conservative outer enclosure. Separation from that enclosure is sufficient evidence of separation; overlap is **NOT_VERIFIED**, not a claim of actual penetration. Its minimum world X is a conservative lower bound for candidate clearance. Shapes with verified native faces and supported primitives retain their separately identified exact geometric checks. An interior witness for the action contract must come from an independently verified exact shape, never from an outer enclosure.

This audit concerns explicitly sampled rigid geometry, with a stated penetration tolerance. It does not certify continuous motion, real material fidelity, contact-force truth, or real-world safety. The independent physics-only gate and original raw failed diagnostic attempts remain separate evidence.
